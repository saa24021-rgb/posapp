    課題提出・環境構築ガイド (GitHub & Firebase Hosting)

    1. GitHubリポジトリ作成 (posapp)

    1. GitHubにて posapp という名前の新しいリポジトリを作成。
    2. この HTML ファイルを index.html として保存。
    3. git init, git add ., git commit 後に GitHub へ Push します。

    2. Firebase Hostingで公開

    1. ターミナルで firebase login および firebase init を実行。
    2. Hostingを選択し、プロジェクト aaaa-7e2ec を指定。
    3. 公開ディレクトリに index.html を配置し firebase deploy で公開完了！
